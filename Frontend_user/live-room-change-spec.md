# 用户端前端修改说明（第二版）

## 1. 本轮目标

本版本只保留当前最新需求，旧需求按已完成处理，不再作为本轮改造范围。

1. 删除用户端“竞拍规则”弹窗（点击规则按钮不再弹窗）。
2. 修复“延时规则”联调：商家端填写多少秒，后端就按多少秒延时，用户端同步显示该秒数。
3. 直播页面左上角新增“退出”按钮：返回到上一个直播列表/直播入口页面。
4. “我的”页面新增“退出登录”按钮：点击后清理登录态并回到登录页。

---

## 2. 详细需求

### 2.1 删除规则界面

- 用户端直播页底部“规则”入口保留或替换文案由 UI 决定，但不得再弹出现有规则弹窗。
- 相关组件不再参与渲染链路，避免误触发遮罩层。

### 2.2 延时规则（商家端 -> 后端 -> 用户端）

#### 商家端

- 商家端配置项统一为“延时秒数”（整数，单位秒）。
- 示例：填写 `30`，表示“最后触发延时时，每次延长 30 秒”。
- 提交参数字段与后端约定一致，禁止前端自行换算单位。

#### 后端联动要求

- 后端应接收并持久化该秒数配置。
- 触发延时时按配置值更新会话结束时间。

#### 用户端显示

- 用户端在拍卖信息中显示延时规则，格式建议：`最后30s内出价自动延长30s`（按真实配置渲染）。
- 倒计时在延时时要实时刷新，不出现前后端秒数不一致。

### 2.3 直播页新增左上角退出键

- 位置：直播页左上角，与顶部信息栏对齐。
- 行为：点击后返回上一级直播页面（优先 `navigate(-1)`，无历史时兜底跳转直播列表路由）。
- 不影响当前直播中的其他状态管理。

### 2.4 “我的”页面新增退出登录

- 新增按钮：`退出登录`。
- 点击后动作：
  - 清理 token / 用户信息 / 本地登录态缓存。
  - 跳转到登录页。
  - 已建立的实时连接需断开并复位状态（如有）。

---

## 3. 接口与数据检查清单

### 3.1 商家端（配置延时）

- 检查提交接口请求体是否包含“延时秒数”字段。
- 检查字段单位是否为秒，是否与后端一致。

### 3.2 用户端（展示延时）

- 检查会话详情接口是否返回延时秒数配置。
- 检查页面展示是否使用接口真实值，而非写死文案。

### 3.3 登录态

- 检查退出登录后访问受保护页面是否会被拦截并要求重新登录。

---

## 4. 验收标准

1. 直播页点击“规则”不再出现旧规则弹窗。
2. 商家端配置 `N` 秒后，后端生效且用户端显示为 `N` 秒。
3. 直播页左上角“退出”可稳定返回上一级页面。
4. “我的”页点击“退出登录”后，登录态清空并回到登录页。
5. 退出登录后刷新页面，不会自动恢复为已登录状态。
