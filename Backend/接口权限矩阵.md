# 接口权限矩阵

这份文档用于明确当前后端各类接口的访问权限。

## 1. 角色说明

- `viewer`：普通用户
- `anchor`：主播
- `admin`：管理员

## 2. 权限规则总表

### 公共接口

- `POST /auth/login`
  - 匿名可访问
- `GET /health`
  - 匿名可访问
- `GET /rooms`
  - 匿名可访问
- `GET /rooms/{roomId}`
  - 匿名可访问
- `GET /rooms/{roomId}/items`
  - 匿名可访问
- `GET /rooms/{roomId}/items/{itemId}`
  - 匿名可访问
- `GET /rooms/{roomId}/current-session`
  - 匿名可访问
- `GET /rooms/{roomId}/events`
  - 匿名可访问
- `GET /rooms/{roomId}/live-snapshot`
  - 匿名可访问
- `GET /sessions/{sessionId}/ranking`
  - 匿名可访问
- `GET /ws?roomId=...`
  - 匿名可连接
  - 如果携带 token，则会校验 token 合法性

### 登录用户接口

- `GET /users/me`
  - 需要登录
- `GET /sessions/{sessionId}/my-status`
  - 需要登录
- `POST /rooms/{roomId}/comments`
  - 需要登录
- `POST /bids`
  - 需要登录
  - 以后端 token 里的用户身份为准
- `GET /users/me/bids`
  - 需要登录
- `GET /users/me/orders`
  - 需要登录

### 主播/管理员接口

- `POST /admin/rooms/{roomId}/items`
  - `anchor` / `admin`
- `PATCH /admin/items/{itemId}`
  - `anchor` / `admin`
- `POST /admin/rooms/{roomId}/queue/reorder`
  - `anchor` / `admin`
- `POST /admin/rooms/{roomId}/queue/next`
  - `anchor` / `admin`
- `POST /admin/sessions/{sessionId}/start`
  - `anchor` / `admin`
- `POST /admin/sessions/{sessionId}/cancel`
  - `anchor` / `admin`
- `POST /admin/sessions/{sessionId}/settle`
  - `anchor` / `admin`
- `GET /admin/rooms/{roomId}/sessions`
  - `anchor` / `admin`
- `GET /admin/orders`
  - `anchor` / `admin`
- `POST /admin/orders/{orderId}/status`
  - `anchor` / `admin`
- `GET /admin/stats/overview`
  - `anchor` / `admin`
- `GET /admin/stats/timeline`
  - `anchor` / `admin`

## 3. 当前实现约定

- 登录成功后返回的是 JWT 风格签名 token
- 后端统一从 `Authorization: Bearer <token>` 解析当前用户
- 出价接口不再信任前端随便传的 `userId`
- 评论、我的状态、我的订单、我的出价都依赖当前登录用户
