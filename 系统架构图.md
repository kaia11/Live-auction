## 如何使用

1. 在 VS Code 中打开本文件
2. 按 `Ctrl + Shift + V` 打开 Markdown 预览
3. 直接查看两张图
4. 如果要放进报告或 PPT，可以截图，或者复制到 Mermaid Live Editor 导出 PNG / SVG
